# 折叠往返侧栏修正

工具按钮原来直接使用 UITabBar 的横竖方向。折叠启动后切到印章或地图再展开，系统标签栏可能保留横向排列；它的方向不能代表系统 Wi-Fi 状态栏的位置。

现改为读取当前 UIWindow 的侧边安全区域、bar layout guide 与预留区域，独立决定工具按钮的横竖排列和横坐标。导航栏及添加按钮继续由原来的布局定位。

在独立 Duo Layout QA 模拟器中实际验证：

- 折叠启动 → 切到印章 → 展开 → 再合上：工具按钮始终在 Wi-Fi 图标下方竖排。
- 同次运行切到地图 → 展开 → 再合上：工具按钮位置正确。
- 展开后点击地图筛选按钮，菜单正常打开。
- iOS Simulator Debug 构建成功；git diff --check 通过。

本目录四张截图分别记录印章和地图展开、再次合上的结果。
