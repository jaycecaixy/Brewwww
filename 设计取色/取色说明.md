# 第一段录屏取色复核

基于 ScreenRecording_10-25-2026 23-04-27_1.MP4（126.468 秒），提取 23 个原始分辨率画面（1398×2034），转换 CoreMedia709 → sRGB 后取样。所有坐标与通道值可在 reference-colors.json 复查，palette.html 展示每个取样区域的无损原像素。

工程已应用：纸张底纹、面板/细边、日历格/星期/数字、强调色、圆形按钮与导航选中态、表单、设置开关、照片夹分区渐变、拍立得边框/文字、照片页背景、地图信息卡/标记/按钮、印章配色。照片夹以多色渐变重建，照片页背景以三段渐变近似，均不宣称纹理或材质像素级完全一致。

纸张主背景、地图卡片纹理取自无控件区域，按原生 3× 比例平铺；外观页可见的前三种纸张也单独提取。录屏中未完整展示的后三种纸张暂共用主背景，无法据此推断原始素材。地图使用 MapKit，原应用为高德，底图配色与图形仍有差异。键盘、照片选择器、系统弹窗由系统绘制。

这是录屏的解码显示色。视频压缩、文字抗锯齿、照片及透明材质会产生颜色范围，不能反推出唯一的原始设计色值。低主色占比的文字与插画标为近似，禁止当成经过设计文件验证的色值。

复现：先编译运行 scripts/extract-reference-frames.swift，再运行 scripts/sample-reference-colors.py、scripts/export-reference-textures.py、scripts/write-color-report.py。

验证：Xcode Debug / iPhone Duo 模拟器编译通过。实际首页截图转换为 sRGB 后，日历面板像素为 [70,62,54]、普通日期格为 [101,90,84]，与参考样本逐通道差值均为 0。该验证仅证明上述平面色，不代表所有渐变、文字、纹理或页面完全一致。预览见 预览/取色复核-首页.png 与 预览/取色复核-照片页.png。

照片夹材质修正：录屏中前袋的 RGB 是与背后照片合成后的显示色，不能当成不透明材质直接使用。现用实际照片层、仅在前袋内部显示的 7 pt 模糊层、70%–84% 棕色着色层和轻描边重建半透明磨砂效果；照片外露部分保持清晰，右侧凸起与前袋为连续轮廓。透明度和模糊半径是视觉匹配参数，不能由录屏唯一反推出原始参数。系统开启「降低透明度」时使用不透明后备样式。验证预览：预览/照片夹-半透明.png。
